# Sprint planning

## Purpose

Commit to a sprint goal and a set of backlog items.

## Steps

1. Read the backlog and the last retro actions.
2. Propose a sprint goal and the items that serve it, sized to capacity.
3. Confirm each item has acceptance criteria and meets the Definition of Ready.
4. ⟨autonomy: confirm the plan with the user⟩

## Done when

- Sprint goal and committed items are recorded.
