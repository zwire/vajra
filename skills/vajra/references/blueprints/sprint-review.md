# Sprint review

## Purpose

Show what was built against the sprint goal and collect feedback.

## Steps

1. List done items against the Definition of Done, with evidence.
2. Demo each to the user (screenshots, recordings, commands).
3. Capture feedback as backlog items.

## Done when

- Each item is accepted or returned with reasons; feedback is in the backlog.
