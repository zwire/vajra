# Retro

## Purpose

Turn experience into structural change, including changes to this workflow skill.

## Steps

1. Collect what went well, what hurt, and what surprised.
2. For each pain, find where it entered the workflow (which playbook, which step).
3. Propose at most three changes. Prefer changing a playbook step or gate over adding a rule.
4. Check phase signals: did an experiment get a response far above normal (explore → expand)? Are growth drivers known and stable (expand → extract)?
5. If the workflow should change, run vajra in Evolve mode.

## Done when

- Changes are recorded, and the workflow skill is updated or explicitly left as is.
