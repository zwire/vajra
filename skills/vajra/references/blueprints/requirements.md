# Requirements

## Purpose

Capture fixed requirements with identifiers for traceability.

## Steps

1. Elicit functional and non-functional requirements; give each an id (REQ-n).
2. Write each as verifiable: condition, behavior, measure.
3. Resolve ambiguities with the user; record open questions.
4. [human-gate] Requirements baseline sign-off.

## Done when

- A signed-off requirements list with ids exists.
