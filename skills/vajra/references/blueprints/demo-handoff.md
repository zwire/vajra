# Demo handoff

## Purpose

Package a PoC or prototype for a stakeholder without implying it is production-ready.

## Steps

1. Write the demo script: what to show, in what order, expected output.
2. List what is faked, hard-coded or missing.
3. Rehearse the script once and capture the output.

## Done when

- Script, limitations list and rehearsal evidence exist.
